## 🛡️ 3. Port- og Overgangsregler (Fail-Closed Doktrine)

Enhver tilstandsovergang på tvers av byens grenser er strengt deterministisk og styres av absolutte overgangsinvarianter:

```text
DIRECT_RAW_TO_OPEN = KILL
HOLD_IMPLIES_OPEN  = FALSE
WITNESS            = APPEND_ONLY (SHA-256 Hash Chained & Disk Persistent)
PHYSICAL_AUTHORITY = 0.00V DC Galvanisk Interlock (Fail-Closed Crowbar)
INSPIRED_BY       != IMPLEMENTS != PROVES
```

### Overgangsmatrise:
* **$\text{RAW } (0\text{x}01) \longrightarrow \text{HOLD}$:** Tillatt for reversibel hypotesetesting og teoretisk modellering i NP-rommet.
* **$\text{RAW } (0\text{x}01) \longrightarrow \text{OPEN}$:** **STRENGT FORBUDT (`KILL`)**. Ingen snarvei utenom formell autorisasjonsport.
* **$\text{HOLD} \longrightarrow \text{OPEN } (0\text{x}02)$:** Krever 100 % oppfylt evidenskontrakt:
  * Entydig, ikke-tom evidens-ID.
  * Deterministisk testverifikasjon (L1 software gate passert).
  * SHA-256 hash-lås og WORM-registrering.
  * For fysiske påstander: Ekstern uavhengig laboratoriegjenskapelse før status heves over `HOLD`.
* **Avvik / Feil / Timing-divergens $\longrightarrow$ `KILL` ($0.00\text{ V}$):**  
  All fiktiv autoritet kollapser øyeblikkelig. Kontrollskinnen kortsluttes til jord på nanosekunder.

## 🧭 4. Porteføljens Styringskontrakt v0.4

1. **Den Offentlige Kvartettens Renhet:**  
   `epistemic-architectures`, `epistemic-architectures-notes`, `ky-rox-public-demonstrators` og `loop-engineering` representerer de åpne, uavhengig etterprøvbare søylene. De skal **aldri** inneholde hemmelig IP, proprietære VHDL-nettister, eller udokumenterte påstander.
2. **Beskyttelse av IP-Kjernen:**  
   `femos-biomimetic-nitrogenase` forblir **STRENGT PRIVAT**. Offentlige wikier og dokumenter refererer kun til overordnede L1-prinsipper og formelle grenser, aldri til interne filstier eller patenterbare kjemiske synteser.
3. **Deterministisk Synkronisering:**  
   Hver endring i den offentlige porteføljen må være konsistent med de tre publiserte Zenodo-postene ([`18436983`](https://doi.org/10.5281/zenodo.18436983), [`18515422`](https://doi.org/10.5281/zenodo.18515422), [`22229111`](https://doi.org/10.5281/zenodo.22229111)), forfatterens ORCID-post, og de fem offisielle GitHub-wikiene.

   Offentlige repositorier holdes på `main`, med eksplisitte release-tags og automatiserte CI-porter som håndhever tillatte fillister.
